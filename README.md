# Solar System Portfolio - Suraj Prakash

A stunning 3D interactive portfolio built with React, Three.js, and Framer Motion. Explore my professional journey through a celestial lens.

## 🚀 Features

- **3D Solar System**: Interactive planets representing different portfolio sections.
- **Smooth Navigation**: GSAP-powered camera transitions and focal zooming.
- **Interactive UI**: Glassmorphic overlay panels with Framer Motion animations.
- **Responsive Design**: optimized for both desktop and mobile explorers.
- **Loading Sequence**: Immersive galaxy initialization animation.

## 🛠️ Tech Stack

- **Frontend**: React, React Three Fiber, Three.js, Tailwind CSS, GSAP, Framer Motion.
- **Backend (Planned)**: Node.js, Express, MongoDB.
- **Icons**: Lucide React.
- **Deployment**: Vercel (Frontend), Railway/Render (Backend).
